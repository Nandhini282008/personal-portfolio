# Personal Portfolio Website

A responsive one-page portfolio built with semantic HTML5 and CSS.

## Run locally
Open `index.html` in your browser.

## Customize before publishing
1. Replace `Your Name` and `YN` with your name and initials.
2. Update the introduction and skill list to match your experience.
3. Replace the three sample project cards and their GitHub URLs with your real projects.
4. Replace the LinkedIn, GitHub, and email links with your own.
5. Check the page on a phone and desktop.

## Publish free with GitHub Pages
1. Create a GitHub repository named `personal-portfolio`.
2. Upload `index.html`, `style.css`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site. The live URL will appear in the Pages section.

## Design decision
The layout uses a calm green palette and generous spacing to keep the content easy to scan. CSS Grid handles the main section and project layouts, while Flexbox aligns navigation, buttons and skill cards. Media queries stack the layouts on smaller screens.
